# 품질 백로그 — 2026-08 전면 점검

에뮬레이터 실사용 QA + 6갈래 코드 정밀 점검(접근성·i18n·아동UX / 성능·안정성 / domain·data /
presentation 2차 / 콘텐츠 d3~5 / 리텐션 리서치)에서 **250건 이상**을 발견했다.
이 문서는 **아직 안 고친 것의 대장**이다. 고친 것은 커밋 이력에 있다.

> 원칙: 발견은 기록하고, 적용은 근거와 검증이 갖춰진 것부터. 이 파일에 없는 걸 고쳤다면 여기서 지운다.

## 판단 보류 (반례가 있어 신중히)

- **수집물·배지·마스코트 확대**: 성과 조건부 재화는 내재 동기를 훼손(Deci 1999). 커스터마이징은 초등 실험에서 null result. 마스코트는 "말하는 화자"까지만.
- **연출 강화**: seductive details 메타 g = −0.33. 정답 연출을 키우면 오답 시 침묵이 상대적 처벌로 읽힌다.
- **힌트에 벌점**: 회피를 유발(Khan 사례). 대신 힌트 2단계↑ 사용 정답은 **승급 카운트에서만 제외**.

근거·출처 상세는 각 조사 리포트와 `docs/PEDAGOGY.md` 참조.
