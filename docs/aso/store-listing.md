> **이 문서의 위치**: `docs/store/LISTING.md`가 "현재 등록본"의 단일 출처라면, 이 문서는
> **검색 유입을 목적으로 한 재작성안**이다. 확정되면 LISTING.md를 이 내용으로 갱신한다.
>
> **작성 기준일**: 2026-08-30 · 대상 버전 v1.0.0(versionCode 17) 등록본

## 0. 먼저 — 문구보다 앞서는 문제

**v1.0.0에는 첫 문제를 채점한 뒤 두 번째 문제부터 제출이 막히는 버그가 있다**(PR #36에서 수정,
아직 미배포). ASO 문구 교체는 이 버그와 무관하므로 **지금 해도 된다.** 그러나 **홍보로 유입을
만드는 일은 v1.0.1 배포 이후**여야 한다 — 자세한 이유와 순서는
[`docs/marketing/launch-plan.md`](../marketing/launch-plan.md)의 "선행 조건"을 볼 것.

## 1. 현재 문구 진단

### 1-1. 현재 등록본 (2026-08-30 기준)

| 필드 | 현재 값 | 글자 수 |
|---|---|---|
| 앱 이름 | `딱풀: 초등 사고력 수학` | 13 / 30 |
| 짧은 설명 | `5분 생각하는 사고력 수학. 실력에 맞춰 다음 문제 자동 추천, 단계별 풀이와 학습 리포트까지.` | 53 / 80 |
| 자세한 설명 | "딱풀은 **유아부터 성인까지**…"로 시작 | 1,199 / 4,000 |

### 1-2. 진단 — 왜 검색에 안 잡히는가

**① 가장 큰 문제: 이름과 본문의 타깃이 어긋난다**

앱 이름은 "초등"인데 자세한 설명 첫 문장은 "유아부터 성인까지"다. Play의 검색 알고리즘은
제목·짧은 설명·자세한 설명의 **일관된 신호**를 본다. 두 신호가 다른 대상을 가리키면 어느 쪽으로도
강하게 잡히지 않는다. 사용자에게도 "누구를 위한 앱인지" 흐려 보인다.

**② 짧은 설명 53자 — 80자 중 27자를 버리고 있다**

짧은 설명은 제목 다음으로 가중치가 높은 필드다. 32자는 키워드 2~3개를 더 넣을 수 있는 분량이다.
현재 문구에는 **"초등"도, "문제집"도, "학습"도 없다.**

**③ 자세한 설명 1,199자 — 4,000자 중 2,800자를 버리고 있다**

분량 자체가 랭킹 요소는 아니지만, 자연스럽게 담을 수 있는 키워드 수가 그만큼 줄어든다.
특히 학부모가 실제로 검색하는 **학년 표현("3학년", "4학년")이 단 한 번도 등장하지 않는다.**

**④ 빠진 핵심 키워드**

현재 등록본 전체를 검색해 확인한 결과, 아래 표현이 **한 번도 나오지 않는다**:

| 빠진 표현 | 왜 중요한가 |
|---|---|
| 초등학생 / 초등 3학년·4학년·5학년·6학년 | 학부모는 학년을 붙여 검색하는 경향이 있다(2-1의 자동완성으로 검증 필요) |
| 문제집 / 학습지 / 워크북 | "앱"이 아니라 "문제집"으로 검색하는 층이 두껍다 |
| 도형, 규칙 찾기, 논리, 퍼즐 | 사고력 하위 유형 검색어 |
| 영재원, 경시 | 상위권 학부모의 강한 구매 의도 검색어 |
| 오답 노트 | 실제 있는 기능인데 문구에 없다 |

**⑤ 실제 있는 기능인데 문구에 없는 것**

소스에서 확인했으나 등록본에 언급이 없는 기능:
- **오답 노트** (`presentation/review/`) — 틀린 문제만 모아 다시 풀기
- **학습지 인쇄** (`presentation/print/`) — 문제를 A4 PDF로 뽑아 종이로 풀기
- **읽어주기** (`presentation/common/tts/`) — 문제를 소리로 읽어줌
- **연습장** (`solve/Scratchpad.kt`) — 화면에서 바로 끄적이며 풀기
- **한/영 전환** — 앱 안에서 언어를 바꾸면 문제까지 영어로

이 중 **학습지 인쇄와 오답 노트는 학부모에게 강한 소구점**인데 그냥 비어 있다.

### 1-3. 진단 요약

> 현재 등록본은 **"잘 쓴 소개문"이지만 "검색되는 문서"는 아니다.**
> 앱의 철학(계산 드릴이 아니다, 보상으로 낚지 않는다)은 잘 담겨 있으나,
> 학부모가 실제로 검색창에 치는 말이 거의 들어 있지 않다.

## 2. 키워드 리서치

### 2-1. 이 표를 읽는 법 (중요)

**아래 "경쟁 강도"는 정량 데이터가 아니라 정성 추정이다.** 우리에게는 Play Console의 검색어
데이터가 아직 없고(설치가 거의 없어 데이터 자체가 쌓이지 않았다), 외부 ASO 도구도 쓰지 않았다.
따라서 각 등급은 **"Play 검색 시 상위에 어떤 규모의 앱이 나오는가"** 라는 관찰 가능한 기준으로
추정했으며, 아래 "검증 방법"으로 직접 확인한 뒤 갱신할 것을 전제로 한다.

**검증 방법 (30분이면 된다)**
1. Play 스토어 앱에서 각 키워드를 **끝까지 치지 말고** 한 글자씩 입력 → **자동완성 목록**을 기록한다.
   자동완성에 뜨는 표현이 곧 실제 검색량이 있는 표현이다.
2. 검색 후 **상위 5개 앱의 다운로드 수**를 본다. 10만+ 앱이 5개면 경쟁 높음, 1만 미만이 섞여 있으면 진입 여지.
3. 배포 2주 후 **Play Console → 사용자 확보 → 검색어**에서 실제 유입 검색어를 확인해 이 표를 갱신한다.

### 2-3. 표에 붙는 주석 (여기가 실제 판단이 갈리는 부분)

**※ #5 학년 키워드 — 딜레마와 해법**

이 앱에는 **학년 개념이 없다.** 난이도 1~10 한 축으로만 나눈다(`Difficulty.kt`).
그런데 학부모는 "초등 4학년 수학"으로 검색한다. 여기서 흔한 실수는 문구에
"4학년 과정 완벽 대비" 같은 말을 넣는 것인데, **이건 사실이 아니라서 쓰면 안 된다.**

**해법**: 학년이라는 단어를, 앱의 차별점을 설명하는 문장 안에서 쓴다.

> "같은 4학년이라도 실력은 제각각입니다. 딱풀은 학년 대신 난이도로 맞춥니다."

이러면 ① 검색어가 문서에 포함되고 ② 거짓말이 아니며 ③ 오히려 차별점이 강조된다.
아래 자세한 설명 완성본에 이 방식으로 넣었다.

**※ #12 영재원·경시 — 사실이지만 메인은 아니다**

난이도 5~10에 경시·올림피아드급 문항이 실제로 존재한다(`Difficulty.MAX = 10` 주석 근거).
다만 **기본 상태에서는 난이도 1~4(477문항)만 노출**되고, 5 이상은 설정에서 직접 열어야 한다
(`DEFAULT_OPEN_MAX = 4`). 따라서 "경시 대비 앱"으로 전면에 내세우면 설치 직후 기대와 어긋난다.
**본문 중반에 "더 올라가고 싶다면" 맥락으로만** 배치한다.

**⚠️ #15 "무료" — 제목·아이콘 금지, 본문은 허용**

Play 정책상 **제목/아이콘/그래픽에 "무료·1위·할인·이모지"를 넣으면 반려**될 수 있다.
본문과 스크린샷 캡션의 사실 서술은 허용된다(`docs/store/LISTING.md`의 기존 조사와 동일).

**❌ #16 연산·구구단 — 넣지 말 것**

검색량은 크지만 **이 앱은 계산 드릴을 의도적으로 배제한다**(프로젝트 헌법 1순위, `CLAUDE.md`).
이 키워드로 유입된 사용자는 앱을 열자마자 기대와 다른 화면을 보고 이탈한다.
**설치 후 이탈은 Play 랭킹에 직접 악영향**이므로, 검색량이 커도 손해다.
대신 본문에 **"계산 드릴이 아닙니다"** 라고 명시해 오해로 인한 설치를 미리 걸러낸다.

## 3. 앱 이름 필드 최적화

### 3-1. 판단: 붙인다. 단 2단어까지만

Play 제목은 **30자**이고 검색 가중치가 가장 높은 필드다. 현재 `딱풀: 초등 사고력 수학`은 13자로
**17자를 놀리고 있다.** 다만 키워드를 욕심껏 나열하면 스팸으로 반려될 수 있으므로,
**자연스러운 명사구 하나만** 덧붙인다.

### 3-2. 후보

**A안 (권장)**
```
딱풀: 초등 사고력 수학 문제집
```
- 17자. `초등` `사고력` `수학` `문제집` 4개 키워드가 자연스러운 한 구절로 들어간다.
- "문제집"은 **앱을 문제집의 대체재로 찾는 층**을 잡는다(#4, #11). 실제로 학습지 인쇄 기능이
  있어 문구가 과장이 아니다.
- 반려 위험 낮음: 금지어 없음, 나열이 아니라 하나의 명사구.

**B안**
```
딱풀: 초등 사고력 수학 · 문제 추천
```
- 19자. 적응형 추천이라는 **핵심 차별점**을 제목에 노출.
- 다만 "문제 추천"은 검색어로서는 약하다(학부모가 이렇게 검색하지 않는다).

**C안 (보수적)**
```
딱풀: 초등 사고력 수학
```
- 현행 유지. 이름 변경은 기존 사용자의 인지에 혼란을 줄 수 있는데,
  **현재 설치 수가 매우 적어 그 리스크는 사실상 없다.** 지금이 바꾸기 가장 좋은 때다.

→ **A안을 권장한다.**

### 3-3. 이름 변경 시 주의

- 제목 변경은 Play 심사를 다시 거친다(보통 수시간~1일).
- **아이콘·피처그래픽에는 텍스트 키워드를 넣지 말 것** — 별도 반려 사유다.
- 변경 전후 날짜를 [`metrics.md`](metrics.md)의 기록 템플릿에 남겨 효과를 측정한다.

## 4. 짧은 설명 (80자) — 후보 3개

> 짧은 설명은 **앞 26자 정도가 검색 결과 목록에서 먼저 보인다.** 승부는 거기서 난다.

### A안 — 검색 최적 (권장)

```
초등 사고력 수학 문제집. 학년 대신 실력에 맞춰 문제를 골라주고, 오답 노트와 학습 리포트까지.
```
- **54자.** 앞 12자에 `초등` `사고력` `수학` `문제집` 최우선 키워드 4개가 모두 들어간다.
- "학년 대신 실력에 맞춰"로 **차별점을 한 구절에 압축**.
- `오답 노트`(#10)와 `리포트`까지 담아 기능 키워드를 확보.

### B안 — 차별점 강조

```
계산 드릴이 아닌 초등 사고력 수학. 연습장 펴고 5분 생각하는 문제, 실력 맞춤 추천과 부모 리포트.
```
- **57자.** "계산 드릴이 아닌"을 앞세워 **부적합 설치를 걸러낸다**(#16 대응).
- 다만 앞 26자를 부정문에 쓰는 셈이라, 검색 노출 관점에서는 A안보다 약하다.

### C안 — 신뢰 강조

```
초등 사고력 수학. 광고·결제 없이 오프라인으로, 실력에 맞는 문제 추천과 보호자 학습 리포트.
```
- **53자.** 광고 없음·오프라인은 **학부모의 강한 선택 기준**이며 우리의 확실한 강점이다.
- 다만 `문제집` `오답 노트` 같은 검색어를 놓친다.

### 권장 조합

**A안으로 시작**하고, 4~6주 뒤 Play Console의 전환율 데이터를 보고 C안과 A/B 테스트
(Console → 스토어 등록정보 실험). 근거는 [`metrics.md`](metrics.md).

## 5. 자세한 설명 (4,000자 이내) — 완성본

> 아래 블록을 **그대로 복사해 붙여넣으면 된다.** **1,962자**(공백 포함, 4,000자 제한 내).
> 첫 3줄은 스토어에서 "더보기" 전에 보이는 구간이라 가장 공들여 썼다.
> 키워드는 **문장 안에 자연스럽게** 넣었고, 나열식 스터핑은 하지 않았다.

```
초등 사고력 수학 문제집 앱, 딱풀입니다.

틀린 문제는 날짜별로 오답 노트에 모입니다. 나중에 다시 풀어 볼 수 있고, 다시 푼 기록은 학습 난이도에 영향을 주지 않아 부담 없이 복습할 수 있습니다.

✏️ 연습장은 화면 안에

문제를 보다가 바로 그 자리에서 끄적일 수 있습니다. 종이를 찾으러 자리를 뜨지 않아도 됩니다.

⏱️ 하루 목표는 아이가 정합니다

하루에 몇 문제를 풀지 아이가 직접 고릅니다(5문제, 10문제, 15문제). 목표를 채우면 그날의 축하가 있고, 며칠 이어서 풀면 연속 학습일이 쌓입니다. 오래 앉아 있으면 "오늘은 여기까지 어때요?" 하고 먼저 권합니다. 붙잡아 두는 대신 스스로 멈출 줄 알게 하려는 설계입니다.
```

### 5-1. 이 문구에서 의도적으로 **하지 않은** 것

| 하지 않은 것 | 이유 |
|---|---|
| "1위", "최고의", "완벽 대비" | Play 과장 광고 정책 위반 소지 |
| "○학년 교과 과정 완벽 반영" | **사실이 아니다.** 교과 진도 기반이 아니라 난이도 기반이다 |

| 키워드 나열 문단 | 스터핑은 반려 사유이자 가독성 파괴 |
| "1,053문항"이라는 정확한 수 | 문항은 업데이트마다 바뀐다. "1,000문항이 넘게"가 안전하고 정확하다 |
