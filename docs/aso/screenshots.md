# 스크린샷 구성안 (8장)

> **현재 상태** (2026-08-30 확인): 폰 5장(`docs/store/marketing/ss1~ss5.png`) +
> 태블릿 3장(`tab1~tab3.png`)이 캡션 오버레이까지 렌더된 상태로 업로드돼 있다.
> **Play는 폰 최대 8장** — 3장이 비어 있다.
>
> 생성기: `docs/store/marketing/gen_store_assets.py`(폰) / `gen_tablet_assets.py`(태블릿)
> 원본 캡처: `docs/store/screenshots/phone/`, `docs/store/screenshots/tablet/`

## 0. 왜 8장을 다 채우는가

Play 검색 결과 목록에서 사용자는 **아이콘 + 첫 2장**만 보고 스크롤한다.
상세 페이지에 들어와서도 대부분 3~4장까지만 넘긴다. 그럼에도 8장을 채우는 이유는:

1. **빈 슬롯은 "만들다 만 앱"으로 읽힌다** — 설치 결정에 직접 영향.
2. 뒤쪽 장은 **이미 관심 있는 사람의 마지막 의심을 없애는** 역할을 한다
   (가격은? 광고는? 우리 아이 수준에 맞나?).
3. 스크린샷 캡션의 텍스트도 **일부 검색 신호로 쓰인다**(공식 확인은 안 되나 손해는 없다).

## 2. 1장 — 광고판 (가장 중요)

### 목표
0.5초 안에 **"계산 반복 시키는 앱이 아니구나"**를 전달한다.
초등 수학 앱 검색 결과는 연산 드릴 앱으로 가득하다. 우리는 **그 반대라는 것**이 유일한 훅이다.

### 화면
현재 `ss1.png`의 **쌓기나무 문제를 그대로 유지한다.** 이유:
- 그림이 있어 썸네일 크기에서도 "수학 문제"임이 즉시 읽힌다.
- 숫자 나열이 아니라 **입체 도형**이라 드릴 앱과 시각적으로 확실히 구분된다.
- "보이지 않는 뒤·아래 나무도 세어요"라는 지문이 곧 사고력 문제의 정의다.

### 캡션 (현재 → 수정)

현재:
```
5분 생각하는
사고력 문제
계산 드릴이 아니라, 연습장 펴고 푸는 문제
```

수정안:
```
계산 드릴이 아니라
생각하는 문제
초등 사고력 수학 · 연습장 펴고 5분
```

**바꾸는 이유**: 현재 캡션의 큰 글씨는 "5분 생각하는"인데, 이건 **혜택이 아니라 방식**이다.
학부모가 찾는 것은 "우리 애가 문장제에서 막히는데"이고, 그 반대말은 "계산 드릴"이다.
큰 글씨에 **대비(계산 ↔ 생각)** 를 놓아야 0.5초 안에 읽힌다.
작은 글씨에는 최우선 키워드 `초등 사고력 수학`을 넣는다.

## 3. 2장 — 차별점 (신규, 두 번째로 중요)

### 목표
"실력에 맞춰 골라 준다"는 **이 앱의 핵심 메커니즘**을 보여준다.
현재 8장 어디에도 이걸 시각적으로 보여주는 장이 없다 — 가장 큰 공백이다.

### 화면
난이도가 올라가는 흐름이 보이는 화면. 두 가지 방법:

**방법 A (권장 · 실제 화면)**: 리포트의 **숙달 지도**를 크게. 난이도 축이 있고 칸이
채워진 모습이 "단계가 올라간다"를 그림 하나로 보여준다.
캡처 위치: 리포트 탭 → 아래로 스크롤 → "레벨별 숙달 지도".

**방법 B (합성)**: 문제 카드 3개를 계단처럼 배치하고 `Lv.2 → Lv.3 → Lv.4` 뱃지를 강조.
`gen_store_assets.py`에 합성 슬라이드를 추가해 렌더.
⚠️ 합성 이미지는 **실제 화면과 다르면 정책 위반**이다. 실제 문제 카드를 그대로 쓰고
배치만 바꾸는 선에서만 허용.

→ **A안 권장.** 실제 화면이고 제작이 간단하다.

### 캡션
```
학년 대신
실력에 맞춰
맞히면 조금 더 어렵게, 틀리면 한 걸음 뒤로
```

## 4. 3~5장 — 이해와 부모 (현행 유지)

### 3장 · 정답 + 단계별 풀이 (`ss2.png` 유지)
현재 캡션이 "실력 따라 다음 문제 자동 추천 / 단계별·심화 풀이로 이해까지"인데,
**앞부분(자동 추천)이 새 2장과 겹친다.** 풀이에만 집중하도록 수정:
```
답만 알려주지
않습니다
왜 그렇게 푸는지 한 줄씩 · 틀린 이유까지
```

### 4장 · 리포트 숙달 지도 (`ss3.png` 유지)
```
부모님을 위한
성장 리포트
어디가 강하고 어디를 더 볼지, 다음 한 걸음까지
```

### 5장 · 영역별 성취 (`ss4.png` 유지)
```
네 영역을
고르게
수와 연산 · 변화와 관계 · 도형과 측정 · 자료와 가능성
```

## 5. 6장 — 오답 노트 (신규)

### 왜 넣는가
`presentation/review/`에 실제로 있는 기능인데 **스토어 어디에도 없다.**
"틀린 문제 다시 풀기"는 학부모가 문제집을 고를 때 보는 조건 중 하나다.

### 화면
오답 노트 화면 (홈 또는 리포트 → "오답 노트 열기"). 날짜별로 틀린 문제가 쌓인 목록.

### 캡션
```
틀린 문제는
여기 모여요
날짜별로 쌓이고, 언제든 다시 풀 수 있어요
```

---

## 6. 7장 — 학습지 인쇄 (신규)

### 왜 넣는가
`presentation/print/`의 실제 기능. **"화면 그만 보게 하고 싶다"는 학부모의 니즈**를
정면으로 건드리는, 수학 앱으로서는 드문 소구점이다.
앱 이름에 넣기로 한 "문제집"이라는 단어를 **뒷받침하는 증거**이기도 하다.

### 화면
인쇄 미리보기 화면 또는 A4 학습지 PDF 레이아웃.
캡처 방법은 `.claude/skills/emu-qa`의 "PDF 검증 = 시스템 인쇄 미리보기 캡처" 참고.

### 캡션
```
종이로도
풀 수 있어요
문제와 리포트를 A4로 인쇄
```

## 7. 8장 — 신뢰 (`ss5.png` 유지)

마지막 장은 **설치 직전의 마지막 의심**을 지운다.
```
안심하고
맡기는 학습
광고 없음 · 결제 없음 · 회원가입 없음 · 오프라인
```

⚠️ **"무료"라는 단어를 이미지에 크게 넣지 말 것.** 본문 서술은 허용되나
그래픽 강조는 반려 위험이 있다(`docs/store/LISTING.md` 정책 메모).
"결제 없음"은 같은 사실의 안전한 표현이다.

## 8. 캡션 작성 규칙 (신규 장 만들 때 지킬 것)

1. **큰 글씨 2줄, 각 5~7자.** 썸네일에서 읽히는 건 여기까지다.
2. 큰 글씨는 **혜택**, 작은 글씨는 **근거**. 기능 이름을 큰 글씨에 쓰지 않는다.
3. 문장 부호로 끝내지 않는다(마침표 없음).
4. **금지**: 최고/1위/완벽/무료(그래픽 한정), 이모지, 경쟁 앱 언급, 순위·수상 주장.
5. 폰트·색은 `gen_store_assets.py`의 기존 값을 그대로 쓴다 — 8장의 톤이 어긋나면
   오히려 조악해 보인다.

## 9. 태블릿 (3장 유지 + 1장 추가 검토)

현재 `tab1~tab3`(사고력 문제 / 성장 리포트 / 신뢰). 태블릿은 폰보다 슬롯 압박이 적고
**태블릿 우선 앱**이므로 최소 3장은 유지한다.
여유가 되면 **학습지 인쇄** 1장을 추가한다 — 큰 화면에서 인쇄 레이아웃이 잘 보인다.
