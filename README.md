# 딱풀 (DdakPul)

> "딱 맞는 문제를 풀다" — 전 연령 적응형 사고력 수학 학습 앱

문제를 풀면 정답 여부와 누적 실력 데이터를 바탕으로 **다음에 풀 문제를 온디바이스에서 자동 추천**한다.
추천은 서버·외부 API 없이 순수 규칙 기반 알고리즘으로 동작하므로 **런타임 비용이 0원**이고, **오프라인**에서 완결된다.

- **타깃**: 초등부터 성인까지 — 학년이 아니라 **사고력 난이도 1~10** 한 축(1=유아·초등 입문, 최상위=경시·올림피아드급)
- **문제**: 계산 드릴 금지 — 연습장 펴고 생각하는 다단계 사고력 문제 1,053+ (한/영 이중언어, 전 문항 솔버 검증)
- **디바이스**: 안드로이드 태블릿 우선(폰 대응) · **패키지**: `com.ddakpul.math`

## 핵심 흐름

```
홈(오늘의 목표·복습 카드·실력 지도) → 문제 풀기(연습장·읽어주기) → 채점 바텀시트(해설·심화·영상·오개념)
        → 다음 문제 자동 추천 → 반복      └ 오답 노트(복습 재풀이) · 부모용 리포트 → 학습지 인쇄(A4 + 정답지)
```

주요 기능:
- **적응형 추천** — 온디바이스 규칙 기반. 연속 정답/오답에 따른 승급·강등, 정체 감지 시 해설+선수 개념 복귀,
  오답 직후 재도전, Leitner 간격 복습(1·3·7·14·30일), 하루 중복 금지 + 4영역 균형 출제
- **채점 피드백** — 문제 위 바텀시트로 단계별 풀이 + 심화 풀이 + 흔한 실수(오개념) 교정, 성장 마인드셋 문구.
  막히면 '모르겠어요 · 풀이 보기'로 풀이부터 학습(오답 기록 → 오답 노트 연계)
- **오답 노트** — 틀린 문제를 날짜별로 모아 복습 재풀이, 다시 맞히면 졸업
- **동기부여** — 오늘의 목표(5/10/15문항 선택) 진행, 관대한 스트릭, 과정 칭찬(보상 미끼 없음)
- **학부모 리포트** — 문장형 인사이트('다음 한 걸음' 코칭), 학습량·성장 차트, 영역×난이도 숙달 지도
- **인쇄 학습지** — A4 문제지(풀이 공간 포함) + 정답·해설 별지, 오답 위주/추천 출제
- **부가** — 도형 문제 그림 렌더링(10종+), 문제 읽어주기(TTS), 손글씨 연습장, 동영상 해설(파일럿), 앱 내 한/영 전환

설계의 교육학적 근거는 [`docs/PEDAGOGY.md`](docs/PEDAGOGY.md)에 정리되어 있다.

## 추천 알고리즘 (비용 0)

문제는 개별이 아니라 **그룹(유사 개념·난이도 묶음)** 단위로 추천한다. 규칙은
[`RecommendNextProblemUseCase`](app/src/main/java/com/ddakpul/math/domain/usecase/RecommendNextProblemUseCase.kt)
에 순수 함수로 구현되고, 규칙 1~8이 각각 단위 테스트로 검증된다.

1. 연속 2회 정답 → 난이도 +1
2. 연속 2회 오답 → 난이도 −1
3. 혼조(정답·오답 반복) → 같은 난이도 유지
4. 정체 감지(같은 난이도 누적 오답 N회 **+ 직전 시도 오답**) → 대표문제 해설 + 선수 개념 복귀
   (직전을 맞혔으면 회복 중 — 발동하지 않는다)
5. 같은 문제 하루 중복 금지(하드) + 그날 가장 적게 낸 영역 우선으로 4영역 균형(소프트),
   그룹 내에선 최근에 안 푼 문제 랜덤
6. 난이도는 1~10으로 clamp
7. 재도전: 직전 1문제만 틀렸으면 같은 그룹의 **다른** 문제로 즉시 성공 경험
8. 간격 복습: 숙달 그룹을 Leitner 박스(1·3·7·14·30일)로, 3문제마다 1복습 슬롯

**우선순위: 4(정체) > 8(복습) > 1·2(승급/강등) > 7(재도전) > 3(유지)**

## 빌드 / 테스트

```bash
./gradlew testDebugUnitTest   # 단위 테스트 (추천 알고리즘 규칙 검증)
./gradlew assembleDebug       # 디버그 APK
./gradlew spotlessApply       # 포맷
./gradlew detekt              # 정적 분석
```

로컬 빌드에는 `local.properties`의 `sdk.dir`(안드로이드 SDK 경로)가 필요하다.
문제은행 생성 파이프라인은 `tools/problemgen/`(독립 솔버 검증 + CI 결정성 게이트) 참조.
